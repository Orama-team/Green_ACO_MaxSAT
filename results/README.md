# Results Directory

This directory stores the raw output logs, execution metrics, and CSV records generated by the experimental pipeline.

- **`checkpoints/`**: Stores temporary state and checkpoint files for long-running experiments. This ensures that if the process is interrupted, it can resume from the last completed task rather than starting over.
- **`shipped/`**: A frozen, authoritative set of benchmark results provided directly with the repository. This allows reviewers to immediately generate the article's figures and tables (using `make_figures.py --use-shipped`) without having to spend hours re-running the heavy computational experiments themselves.

**Pipeline Flow:**
When the scripts in `scripts/` are executed, they write their output CSVs directly to this directory. The figure generation script (`make_figures.py`) then reads these CSV files to produce the final visualizations and markdown tables found in the `figures/` folder.
